# Implementations

Independent implementations of the evidence record format, as reported by their
authors.

This list starts empty on purpose. It holds only implementations whose author has
run the published corpus and reported the rungs their implementation derived, so
every row is checkable against a public report rather than an assertion.

| Implementation | Author | Corpus | Rungs derived | Report |
|---|---|---|---|---|
| none reported yet | | | | |

## How a row gets here

Open an issue in this repository with:

- the implementation name and where its source is
- the command you ran against `grade-floor/cases/`
- the rung your implementation derived for each case
- every case where you disagree with the expected rung, with the reason

Agreement is not the requirement for being listed. A reported disagreement that
names the case, the rung and the reason is the more useful contribution, because
it is the only signal that the published rule text is ambiguous.

Listing is at the maintainers' discretion and is not an endorsement of the
implementation.
